# Archivo de capturas crudas

Acá se archiva, sin editar, todo lo que se procesó desde `inbox/` — organizado por fecha
(`data/raw_captures/2026-09-03/`, por ejemplo). Nunca se borra: sirve como respaldo para poder
verificar más adelante de dónde salió exactamente un dato, si hace falta auditar algo.

Cuando en el futuro se conecte el sistema a EVA/SIU vía navegador (Fase 4, todavía no
implementada), lo que ese proceso lea también se va a archivar acá, de la misma forma — no va a
hacer falta cambiar esta carpeta.
