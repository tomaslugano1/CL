# Snapshots

Cada actualización completa (no las rápidas) guarda acá una foto completa del estado del sistema
en ese momento, como `2026-09-03.json`. Sirve para poder comparar "cómo estaba todo antes" contra
"cómo está ahora" y así detectar automáticamente qué cambió — que es lo que después se resume en
`changelog/CHANGELOG.md`.

Todavía no hay ningún snapshot generado (no hubo ninguna actualización completa aún).
