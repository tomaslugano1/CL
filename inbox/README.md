# Inbox — zona de entrada

Acá pegás o dejás archivos con información nueva: texto copiado de EVA, del SIU, capturas de
pantalla convertidas a texto, avisos de un profesor, lo que sea. Después le pedís a Claude que
haga una "actualización completa" o "actualización rápida" y va a leer lo que haya acá, organizarlo
en los archivos correspondientes de `data/`, y archivar lo procesado en `data/raw_captures/`
(no se borra nada).

No hace falta ningún formato especial — pegá la información tal cual la tengas.
